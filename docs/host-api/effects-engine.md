## 1. Effect ("Lightscript") HTML contract

### 1.1 File/loading model
- An effect = ONE self-contained `.html` file. Ids: bundled = filename (`"Neon Shift.html"`, registry `effects\Side To Side.html`), marketplace = Firebase push id (`-MTwqhnV_LPbIrkfZOfo`). - Folders: `Effects\Static` (stock: Neon Shift, Rainbow, Side To Side, Solid Color), `Effects\Dynamic` (Screen Ambience = uses `engine.zone`; docs say developer effects go in `Effects\Dynamic\` and need app restart). Engine semantic difference Static/Dynamic: UNKNOWN (only observed correlation: Dynamic one uses engine data; API exposes `uses_engine`). ## Engine requirements (summary)

- Headless HTML/canvas renderer at exactly 320x200, CPU raster (Ultralight-like) with rAF at ~16.7 ms, sampling the full page bitmap each frame; support CSS transforms/filters (the HD 'scaled' trick relies on transform:scale(2) on body).
- Lightscript loader: parse <title>, <meta description|publisher>, <meta property label type default min max values tooltip> (types number, hue, boolean, color '#RRGGBB', combobox/list, textfield, sensor), inject `var <prop> = <value>` globals, persist values per effect id, call `on<prop>Changed()` on change (no args) and once at load.
- Inject engine bootstrap: engine.zone.{hue Int16Array(560), saturation Int8Array(560), lightness Int8Array(560), imagedata Uint8ClampedArray(64000)} from a 28x20 HSL grid + 160x100 RGBA screen capture; engine.audio.{freq[200], level dB, rawlevel, width, density}; engine.vision.<meter>; engine.sensors + engine.getSensorValue(name)->{value,units,min,max,type}; engine.getNowPlaying().
- Dispatch page callbacks: onEngineReady(), onCanvasTapped(x,y) (key press -> LED canvas coords), onKeyPressed(keyName), onCanvasApiEvent({sender,event}) from an HTTP listener on 16034 (/canvas/event?sender&event, POST).
- Meter parser for <meta meter=...> (linear/area/ocr_textmatch/ocr_numeric, normalized x/y/width/height, h/s/l and hdr-* ranges, string/confidence, <resolution> overrides) feeding engine.vision; OCR optional (Tesseract in original).
- Device layout engine: per endpoint {x,y,scale{x,y},rotation 0-359,flipped,flippedV,enabled,brightness}; plugin exports Size(), DefaultPosition(), DefaultScale() (0.5-75), LedPositions(); named layouts with layout brightness + global brightness 0-100; per-effect preferredLayout; sample canvas -> device.color(x,y)->[r,g,b], device.subdeviceColor(name,x,y), device.getImageBuffer(x,y,w,h,{outputWidth,outputHeight,format,flipH,flipV}).
- Per-device JS engine thread with Render() cadence control (setFrameRateTarget(fps), setFrameDelay(ms)), calling on<prop>Changed before Render, Shutdown(SystemSuspending) on exit/sleep; honour plugin-side conventions LightingMode Canvas/Forced, forcedColor, shutdownColor, shutdownMode.
- LCD subsystem: @SignalRGB/lcd module with initialize({width,height,circular,circularPreview}), getFrame({format:JPEG|RGB|RGBA|RGB565|NZXT::Q565|NZXT::RGB565,quality}), getImageBuffer; compositor = background layer (canvas | media file | now-playing thumbnail; scaleMode crop/fit/stretch; rotation 0/90/180/270) + foreground LCD-face HTML rendered at LCD size (title/description/publisher required, <meta background="true">, onReady(), rAF re-kick after idle), idle blanking.
- Effect catalog/library: scan bundled Static/Dynamic and user Effects dirs, marketplace catalog JSON (name, description, publisher, type Basic/Advanced/Audio, tags{sort}, requires_pro, image), per-effect presets (save/load/delete state) and palettes.
- Local REST API on 127.0.0.1:16038 (/api/v1/lighting, global_brightness, enabled, next/previous/shuffle, effects[/id][/apply|/presets|/image], scenes/current_layout, scenes/layouts, playlists[/id/play], loadEffect) with the json envelope {api_version,id,method,params,status,data|errors}, and the signalrgb:// URL scheme (effect/apply|install, view/*, app/*, addon/install, -silentlaunch-).
